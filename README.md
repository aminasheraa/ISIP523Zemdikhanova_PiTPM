# Практическая работа №4 :smiley:
**Дисциплина**: Поддержка и тестирование программных модулей

## Тема: Тестирование "белым ящиком"
**Учебный проект:** графическое приложение на WPF для вычисления математических функций и построения графиков с реализацией ручного тестирования методом «белого ящика».
Приложение состоит из трёх страниц и позволяет выполнять вычисления по заданным формулам, выбирать тип функции, а также строить график функции на заданном интервале.

### Цель:
Приобрести практические навыки ручного тестирования
методом "белого ящика".

## Функциональные возможности
#### Страница 1 — Вычисление математической формулы
<img width="695" height="96" alt="image" src="https://github.com/user-attachments/assets/6f1a65ee-4f11-4f15-a1a9-024fc4822445" />

- Ввод исходных данных (x, y, z)
- Проверка корректности ввода:
  - заполненность полей
  - числовой формат
  - недопустимые значения (деление на 0, отрицательное под корнем, ln от отрицательного и т.д.)
- Вычисление значения функции
- Вывод результата
- Очистка всех полей
- Отображение изображения формулы
- Всплывающие подсказки (ToolTip)

#### Страница 2 — Вычисление с выбором функции f(x)
<img width="527" height="167" alt="image" src="https://github.com/user-attachments/assets/e1383d64-8554-4442-a1cd-3b777387269b" />

- Ввод исходных данных (x, b)
- Выбор функции с помощью переключателей:
  - sh(x) — гиперболический синус
  - x²
  - eˣ

- Всплывающие подсказки

#### Страница 3 — Вычисление в цикле и построение графика
<img width="401" height="77" alt="image" src="https://github.com/user-attachments/assets/0d932527-1d2c-427c-bbae-6e2e16d7501b" />

- Ввод:
  - начального значения x0
  - конечного значения xk
  - шага dx
  - параметра b
- Проверка:
  - x0 ≤ xk
  - dx > 0
  - dx ≤ (xk − x0)
- Вычисление значений функции в цикле
- Вывод всех значений x и y 
- Построение графика функции
- Очистка данных
- Всплывающие подсказки
- График реализован с использованием библиотеки System.Windows.Forms.DataVisualization и элемента Chart.

### Ход работы

1. Был создан проект модульного тестирования (UnitTestProject) в среде Microsoft Visual Studio.
