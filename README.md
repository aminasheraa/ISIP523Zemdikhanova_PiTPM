### 1. Описание предметной области
Шифр ADFGVX — это алгоритм, сочетающий замену (с помощью таблицы 6x6) и последующую перестановку символов по ключевому слову. Он был разработан для передачи сообщений, содержащих только буквы латинского алфавита и цифры. В данной работе реализовано графическое приложение, позволяющее автоматизировать процесс кодирования и декодирования.

### 5. Баг-репорт
В ходе разработки по методологии TDD были зафиксированы и исправлены следующие несоответствия:

| ID | Обнаруженный баг | Причина | Решение |
|:---|:---|:---|:---|
| **BUG-01** | Сбой `Encrypt_DifferentKeys...` | Ключи с разным написанием, но одинаковым алфавитным порядком («KEY1» и «KEY2»), не меняли структуру столбцов. | Рефакторинг теста: замена ключей на кардинально разные по порядку (`ABCD` vs `DCBA`). |
| **BUG-02** | Сбой `Decrypt_WrongKey...` | На коротких строках ("HELLO") и ключах одинаковой длины, текст восстанавливался. | Увеличена длина тестовой строки для проверки шифра. |
