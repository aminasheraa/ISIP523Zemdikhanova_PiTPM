# Отладка проекта Fibonacci

В рамках выполнения задания по отладке .NET приложения в Microsoft Visual Studio были использованы следующие способы отладки:

## Использованные методы отладки:

### 1. Точки останова
- Установка точек останова на ключевых строках кода.
- Удаление и перемещение точек останова для фокусировки на проблемных участках.

### 2. Пошаговое выполнение кода
- Использование команды Step Over для пошагового анализа выполнения программы.
- Пошаговый вход в метод Fibonacci() для анализа логики работы функции.

### 3. Окно локальных переменных
- Анализ значений переменных n, n1, n2, sum, i во время выполнения программы.
- Отслеживание изменения состояния переменных на каждой итерации цикла.

### 4. Продолжение выполнения
- Использование команды Continue для ускоренного перехода между итерациями цикла без пошагового выполнения каждой строки.

### 5. Анализ логики программы во время отладки
- Сопоставление ожидаемого результата последовательности Фибоначчи с фактическими значениями переменных.
- Выявление логической ошибки в условии цикла for.
