## Тема: Создание автоматизированных Unit-тестов
**Учебный проект:** консольное приложение Bank, содержащее класс BankAccount, который моделирует работу банковского счета.
Класс реализует основные операции:
- Debit — списание денежных средств со счета
- Credit — пополнение счета
Также был создан отдельный проект модульных тестов BankTests, в котором реализованы автоматизированные тесты для проверки корректности работы методов класса.
Тестирование выполнялось с использованием встроенных средств модульного тестирования в Microsoft Visual Studio.

### Цель:
Провести тестирование разработанных программных модулей с использованием средств автоматизации Microsoft Visual Studio методом "белого ящика".

### Тестируемый класс
Класс BankAccount содержит следующие элементы:

Поля:
  - m_customerName — имя владельца счета
  - m_balance — текущий баланс счета
    
Свойства:
  - CustomerName — возвращает имя владельца
  - Balance — возвращает текущий баланс

Методы:
  - Debit(double amount) — выполняет списание средств
  - Credit(double amount) — выполняет пополнение счета
    
Метод Debit также генерирует исключение ArgumentOutOfRangeException, если: сумма списания больше баланса; сумма меньше нуля.
А метод Credit генерирует исключение ArgumentOutOfRangeException, если сумма пополнения меньше нуля.

### Реализованные модульные тесты
#### Тесты метода Debit
*1. Debit_WithValidAmount_UpdatesBalance*

Проверяет корректное списание средств со счета при допустимой сумме.

*2. Debit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange*

Проверяет, что метод генерирует исключение ArgumentOutOfRangeException, если сумма списания меньше нуля.

*3. Debit_WhenAmountIsMoreThanBalance_ShouldThrowArgumentOutOfRange*

Проверяет, что метод генерирует исключение ArgumentOutOfRangeException, если сумма списания превышает баланс счета.

#### Тесты метода Credit
*4. Credit_WithValidAmount_UpdatesBalance*

Проверяет корректное пополнение счета.

*5. Credit_WhenAmountIsLessThanZero_ShouldThrowArgumentOutOfRange*

Проверяет, что метод генерирует исключение ArgumentOutOfRangeException, если передана отрицательная сумма пополнения.

*6. Credit_WhenAmountIsZero_BalanceShouldNotChange*

Проверяет, что при пополнении на 0 баланс счета не изменяется.

*7. Credit_MultipleCredits_UpdatesBalanceCorrectly*

Проверяет корректную работу метода при нескольких последовательных операциях пополнения.
