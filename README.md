# Отладка проекта Galaxy

В ходе выполнения задания по отладке .NET приложения в Microsoft Visual Studio были использованы следующие способы отладки:

## 1. Точки останова 
- Установка точек останова на ключевых участках кода (в цикле foreach, перед switch, в конструкторе).
- Использование точек останова для приостановки выполнения программы и анализа состояния.

## 2. Пошаговое выполнение кода
- Step Over — выполнение кода построчно без захода внутрь методов.
- Step Into — пошаговый вход внутрь методов и более детальный анализ логики.

## 3. Проверка значений переменных
- Наведение курсора на переменные во время остановки отладчика.
- Просмотр значений полей объектов (например, GalaxyType, MyGType, type).

## 4. Редактирование кода во время отладки 
- Внесение изменений в код во время выполнения программы.
- Попытка исправления ошибок без полной остановки приложения.

## 5. Анализ поведения программы во время выполнения
- Сравнение ожидаемого и фактического результата.
- Поиск логических ошибок (неправильный тип данных, опечатки в `switch`, неправильное использование API).
