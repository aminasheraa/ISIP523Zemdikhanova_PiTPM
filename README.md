# Отладка проекта Letters

В рамках выполнения задания по отладке .NET приложения в Microsoft Visual Studio были использованы следующие способы отладки:

## Использованные методы отладки:

## 1. Точки останова
- Установка точек останова в ключевых местах программы (в цикле for, перед выполнением операций).
- Использование точек останова для приостановки выполнения программы и анализа состояния.

## 2. Пошаговое выполнение кода
- Step Over — выполнение кода построчно без входа в методы.
- Step Into — вход внутрь методов для детального анализа.
- Step Out — выход из текущего метода.

## 3. Просмотр значений переменных
- Использование всплывающих подсказок при наведении курсора на переменные.
- Анализ изменения значений переменных в процессе выполнения программы.

## 4. Окна отладки
- Autos — просмотр автоматически определяемых переменных.
- Locals — просмотр локальных переменных текущего метода.
- Watch — отслеживание выбранных переменных и выражений.

## 5. Выполнение до курсора 
- Быстрый переход выполнения программы к выбранной строке кода без установки постоянной точки останова.

## 6. Анализ стека вызовов 
- Просмотр последовательности вызовов методов.
- Определение, откуда был вызван текущий метод.

## 7. Логический анализ кода
- Сравнение ожидаемого и фактического результата выполнения программы.
- Выявление ошибок в логике программы (например, некорректное формирование строки или работа цикла).

## Вывод
Использование перечисленных инструментов позволило:
- отследить выполнение программы пошагово,
- проанализировать значения переменных,
- понять логику работы кода.
